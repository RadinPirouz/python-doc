# 05 – If Statements

Use `if`, `elif`, and `else` to run code based on conditions.

## Basic If / Else

```python
age = 18
if age >= 18:
    print("Adult")
else:
    print("Minor")
```

## If / Elif / Else

```python
score = 85
if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
else:
    grade = "F"
print(grade)  # B
```

## Comparison and Logical Operators

```python
name = "abbas"
age = 25

if name == "abbas" and age > 20:
    print("Match")

if name == "mmd" or age < 18:
    print("Alternative")

if not (age < 18):
    print("Not a minor")
```

| Operator | Meaning |
|----------|---------|
| `==` | Equal |
| `!=` | Not equal |
| `>`, `<`, `>=`, `<=` | Comparison |
| `and`, `or`, `not` | Logical |
