# 00 – Introduction to Python

This course covers Python from the ground up — variables, control flow, data structures, functions, classes, and the standard library.

## What You Need

* Python 3 installed (`python3 --version`)
* A text editor or IDE
* A terminal

## How to Run Python

**Interactive shell:**

```bash
python3
```

**Run a script:**

```bash
python3 main.py
```
