# Python Boto3 S3 Usage Guide for DevOps Engineers

## 1. Purpose

This document explains how to use Python `boto3` with Amazon S3 and S3-compatible object storage such as MinIO, Ceph RGW, or other private S3 endpoints.

It covers:

* Installing boto3
* Configuring credentials
* Creating an S3 client
* Uploading files
* Downloading files
* Listing objects
* Reading and writing object content
* Deleting objects
* Copying objects
* Generating presigned URLs
* Using multipart uploads
* Working with S3-compatible storage
* Handling errors
* DevOps best practices

---

# 3. Credentials Configuration

## 3.1 Local Development Using AWS CLI

Install and configure AWS CLI:

```bash
aws configure
```

You will be asked for:

```text
AWS Access Key ID
AWS Secret Access Key
Default region name
Default output format
```

This creates:

```bash
~/.aws/credentials
~/.aws/config
```

Example:

```ini
# ~/.aws/credentials
[default]
aws_access_key_id = YOUR_ACCESS_KEY
aws_secret_access_key = YOUR_SECRET_KEY
```

```ini
# ~/.aws/config
[default]
region = eu-central-1
output = json
```

---

## 3.4 Recommended Production Method

For AWS workloads, prefer IAM roles instead of static access keys.

Use:

* IAM Role for EC2
* IAM Role for ECS Task
* IAM Role for EKS ServiceAccount using IRSA
* Lambda execution role
* Temporary STS credentials

Avoid storing long-lived access keys in code, Docker images, Git repositories, or CI logs.

# 4. Creating an S3 Client

Use the low-level client for most DevOps automation because it exposes all service operations.

```python
import boto3

s3 = boto3.client("s3", region_name="eu-central-1")
```

With explicit credentials:

```python
import boto3

s3 = boto3.client(
    "s3",
    endpoint_url="http://localhost:9000",
    region_name="eu-central-1",
    aws_access_key_id="YOUR_ACCESS_KEY",
    aws_secret_access_key="YOUR_SECRET_KEY",
)
```

This is useful for testing, but not recommended for production.

# 5. Recommended Client Configuration

Use `botocore.config.Config` for retries, timeouts, and S3 addressing behavior.

```python
import boto3
from botocore.config import Config

config = Config(
    region_name="eu-central-1",
    retries={
        "max_attempts": 10,
        "mode": "standard",
    },
    connect_timeout=10,
    read_timeout=60,
)

s3 = boto3.client("s3", config=config)
```

# 6. Bucket Naming Rules

S3 bucket names should generally:

* Be globally unique.
* Use lowercase letters, numbers, and hyphens.
* Avoid sensitive information.
* Avoid names that look like IP addresses.
* Avoid dots if you plan to use transfer acceleration or want simpler TLS behavior.
* Be between 3 and 63 characters.

Good examples:

```text
company-prod-backups-eu-central-1
company-staging-artifacts
company-logs-2026
```

Bad examples:

```text
MyBucket
192.168.1.10
customer-secret-data-john@example.com
```

# 7. Uploading Files

## 7.1 Upload a Local File

```python
import boto3
from botocore.exceptions import ClientError

s3 = boto3.client("s3")

def upload_file(local_path: str, bucket: str, key: str) -> bool:
    try:
        s3.upload_file(local_path, bucket, key)
        return True
    except ClientError as e:
        print(f"Upload failed: {e}")
        return False


upload_file(
    local_path="/var/log/app.log",
    bucket="company-prod-logs",
    key="logs/app.log",
)
```

# 14. Checking If an Object Exists

```python
import boto3
from botocore.exceptions import ClientError

s3 = boto3.client("s3")

def object_exists(bucket: str, key: str) -> bool:
    try:
        s3.head_object(Bucket=bucket, Key=key)
        return True
    except ClientError as e:
        error_code = e.response.get("Error", {}).get("Code")
        if error_code in ["404", "NoSuchKey", "NotFound"]:
            return False
        raise


exists = object_exists("company-prod-logs", "logs/app.log")
print(exists)
```

# 18. Moving Objects

S3 does not have a native rename operation. A move is normally:

1. Copy object to new key.
2. Delete old key.

```python
source_bucket = "company-prod-logs"
source_key = "logs/app.log"

destination_bucket = "company-prod-logs"
destination_key = "archive/app.log"

s3.copy_object(
    Bucket=destination_bucket,
    Key=destination_key,
    CopySource={
        "Bucket": source_bucket,
        "Key": source_key,
    },
)

s3.delete_object(
    Bucket=source_bucket,
    Key=source_key,
)
```

# 19. Generating Presigned Download URLs

A presigned URL gives temporary access to a private object.

```python
import boto3
from botocore.exceptions import ClientError

s3 = boto3.client("s3")

def create_presigned_download_url(
    bucket: str,
    key: str,
    expires_in: int = 3600,
) -> str | None:
    try:
        return s3.generate_presigned_url(
            ClientMethod="get_object",
            Params={
                "Bucket": bucket,
                "Key": key,
            },
            ExpiresIn=expires_in,
        )
    except ClientError as e:
        print(f"Could not generate presigned URL: {e}")
        return None


url = create_presigned_download_url(
    bucket="company-private-files",
    key="reports/report.pdf",
    expires_in=900,
)

print(url)
```

Use short expiration times for sensitive data.

# 21. Multipart Upload Configuration

For large files, use managed transfer configuration.

```python
import boto3
from boto3.s3.transfer import TransferConfig

s3 = boto3.client("s3")

MB = 1024 * 1024

transfer_config = TransferConfig(
    multipart_threshold=64 * MB,
    multipart_chunksize=64 * MB,
    max_concurrency=10,
    use_threads=True,
)

s3.upload_file(
    Filename="large-backup.tar.gz",
    Bucket="company-prod-backups",
    Key="db/large-backup.tar.gz",
    Config=transfer_config,
)
```

Recommended DevOps defaults:

```python
TransferConfig(
    multipart_threshold=64 * 1024 * 1024,
    multipart_chunksize=64 * 1024 * 1024,
    max_concurrency=5,
    use_threads=True,
)
```

Tune `max_concurrency` based on:

* Network capacity
* CPU
* Disk I/O
* S3 endpoint limits
* CI/CD runner capacity

# 22. Progress Callback for Uploads

```python
import os
import threading
import boto3

class ProgressPercentage:
    def __init__(self, filename):
        self.filename = filename
        self.size = float(os.path.getsize(filename))
        self.seen_so_far = 0
        self.lock = threading.Lock()

    def __call__(self, bytes_amount):
        with self.lock:
            self.seen_so_far += bytes_amount
            percentage = (self.seen_so_far / self.size) * 100
            print(
                f"\r{self.filename}: "
                f"{self.seen_so_far:.0f}/{self.size:.0f} bytes "
                f"({percentage:.2f}%)",
                end="",
            )

s3 = boto3.client("s3")

filename = "backup.tar.gz"

s3.upload_file(
    Filename=filename,
    Bucket="company-prod-backups",
    Key="db/backup.tar.gz",
    Callback=ProgressPercentage(filename),
)
```

# 25. Error Handling

Use `ClientError`.

```python
from botocore.exceptions import ClientError

try:
    s3.head_object(
        Bucket="company-prod-logs",
        Key="logs/app.log",
    )
except ClientError as e:
    error_code = e.response.get("Error", {}).get("Code")
    error_message = e.response.get("Error", {}).get("Message")

    print("Error code:", error_code)
    print("Error message:", error_message)

    if error_code in ["404", "NoSuchKey", "NotFound"]:
        print("Object not found")
    elif error_code in ["403", "AccessDenied"]:
        print("Access denied")
    else:
        raise
```

Common S3 errors:

| Error                   | Meaning                                                          |
| ----------------------- | ---------------------------------------------------------------- |
| `AccessDenied`          | IAM policy, bucket policy, KMS policy, or object ownership issue |
| `NoSuchBucket`          | Bucket does not exist or wrong account/region                    |
| `NoSuchKey`             | Object key does not exist                                        |
| `InvalidAccessKeyId`    | Wrong access key                                                 |
| `SignatureDoesNotMatch` | Wrong secret key, region, endpoint, or signature version         |
| `ExpiredToken`          | Temporary credentials expired                                    |
| `SlowDown`              | Too many requests or throttling                                  |
| `EntityTooLarge`        | Object too large for single request                              |
| `InvalidBucketName`     | Bucket name does not follow S3 rules                             |

# 28. Complete Reusable S3 Helper Class

```python
import json
from typing import Any
import boto3
from botocore.config import Config
from botocore.exceptions import ClientError


class S3Helper:
    def __init__(
        self,
        bucket: str,
        region_name: str = "eu-central-1",
        endpoint_url: str | None = None,
        access_key: str | None = None,
        secret_key: str | None = None,
        path_style: bool = False,
    ):
        self.bucket = bucket

        s3_config = Config(
            region_name=region_name,
            retries={
                "max_attempts": 10,
                "mode": "standard",
            },
            s3={
                "addressing_style": "path" if path_style else "virtual",
            },
        )

        self.client = boto3.client(
            "s3",
            endpoint_url=endpoint_url,
            aws_access_key_id=access_key,
            aws_secret_access_key=secret_key,
            region_name=region_name,
            config=s3_config,
        )

    def upload_file(self, local_path: str, key: str) -> None:
        self.client.upload_file(local_path, self.bucket, key)

    def download_file(self, key: str, local_path: str) -> None:
        self.client.download_file(self.bucket, key, local_path)

    def put_text(self, key: str, content: str) -> None:
        self.client.put_object(
            Bucket=self.bucket,
            Key=key,
            Body=content,
            ContentType="text/plain",
        )

    def put_json(self, key: str, data: dict[str, Any]) -> None:
        self.client.put_object(
            Bucket=self.bucket,
            Key=key,
            Body=json.dumps(data),
            ContentType="application/json",
        )

    def get_text(self, key: str) -> str:
        response = self.client.get_object(
            Bucket=self.bucket,
            Key=key,
        )
        return response["Body"].read().decode("utf-8")

    def get_json(self, key: str) -> dict[str, Any]:
        return json.loads(self.get_text(key))

    def exists(self, key: str) -> bool:
        try:
            self.client.head_object(
                Bucket=self.bucket,
                Key=key,
            )
            return True
        except ClientError as e:
            error_code = e.response.get("Error", {}).get("Code")
            if error_code in ["404", "NoSuchKey", "NotFound"]:
                return False
            raise

    def list_keys(self, prefix: str = "") -> list[str]:
        keys = []
        paginator = self.client.get_paginator("list_objects_v2")

        for page in paginator.paginate(
            Bucket=self.bucket,
            Prefix=prefix,
        ):
            for obj in page.get("Contents", []):
                keys.append(obj["Key"])

        return keys

    def delete(self, key: str) -> None:
        self.client.delete_object(
            Bucket=self.bucket,
            Key=key,
        )

    def presigned_download_url(
        self,
        key: str,
        expires_in: int = 3600,
    ) -> str:
        return self.client.generate_presigned_url(
            ClientMethod="get_object",
            Params={
                "Bucket": self.bucket,
                "Key": key,
            },
            ExpiresIn=expires_in,
        )
```

Usage:

```python
s3 = S3Helper(
    bucket="company-prod-backups",
    region_name="eu-central-1",
)

s3.upload_file("backup.tar.gz", "db/backup.tar.gz")

print(s3.exists("db/backup.tar.gz"))

url = s3.presigned_download_url("db/backup.tar.gz", expires_in=900)

print(url)
```

For MinIO:

```python

    region_name="us-east-1",
    endpoint_url="http://minio.example.com:9000",
    access_key="minioadmin",
```

# 29. DevOps Best Practices

## Security

* Prefer IAM roles over static keys.
* Never commit AWS credentials to Git.
* Use least-privilege IAM policies.
* Avoid public buckets unless explicitly required.
* Enable bucket versioning for critical data.
* Use encryption at rest.
* Enforce HTTPS/TLS.
* Use short expiration times for presigned URLs.
* Rotate credentials regularly if static keys are unavoidable.
* Be careful with `DeleteObject` and `DeleteObjects`.

## Reliability

* Use paginators for listing objects.
* Use multipart upload for large files.
* Configure retries.
* Handle `ClientError`.
* Add logging around upload, download, delete, and copy operations.
* Validate object existence with `head_object`.
* Avoid loading very large files fully into memory.

## Performance

* Use `upload_file` or `upload_fileobj` instead of raw `put_object` for large files.
* Tune multipart chunk size.
* Tune concurrency based on runner capacity.
* Use prefixes to organize objects efficiently.
* Avoid listing entire buckets when only one prefix is needed.

## CI/CD

* Inject credentials using CI secret variables.
* Avoid printing presigned URLs or credentials in logs.
* Use separate buckets or prefixes per environment:

  * `dev/`
  * `staging/`
  * `prod/`
* Use lifecycle policies for temporary artifacts.
* Use versioned artifact paths:

  * `releases/app/v1.2.3/app.tar.gz`

## Kubernetes

For EKS, prefer IRSA instead of static secrets.

Application pod should receive permissions through a Kubernetes service account mapped to an IAM role.

Avoid this pattern unless absolutely necessary:

```yaml
env:
  - name: AWS_ACCESS_KEY_ID
    valueFrom:
      secretKeyRef:
        name: aws-secret
        key: access-key
```

Prefer workload identity / role-based authentication.

```python
s3.upload_file(
```

```python
for key in s3_helper.list_keys("postgres/"):
```

```python
url = s3_helper.presigned_download_url(
```

# 31. Troubleshooting Checklist

## `AccessDenied`

Check:

* IAM policy
* Bucket policy
* Object ownership
* KMS key policy
* Wrong AWS account
* Wrong bucket
* Missing prefix permission
* SCP restrictions in AWS Organizations

## `SignatureDoesNotMatch`

Check:

* Secret key
* Region
* Endpoint URL
* Signature version
* System clock/time sync
* Path-style vs virtual-host style addressing

## `NoSuchBucket`

Check:

* Bucket name typo
* Bucket region
* AWS account
* Endpoint URL
* S3-compatible storage configuration

## `NoSuchKey`

Check:

* Object key path
* Prefix
* Case sensitivity
* URL encoding
* Whether upload actually succeeded

## Upload is slow

Check:

* Multipart config
* Network bandwidth
* Disk I/O
* Max concurrency
* S3 endpoint latency
* Runner CPU limit
* Proxy or NAT bottleneck
